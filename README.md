# 🍽️ Zomato Restaurant Data Analysis

## 📌 Project Overview

This project performs exploratory data analysis (EDA) on the Zomato restaurant dataset to uncover insights about restaurant ratings, pricing trends, location-based performance, and customer preferences.

The objective is to transform raw restaurant data into actionable business insights using data analysis and visualization techniques.

---

## 🎯 Problem Statement

The restaurant industry is highly competitive. Understanding customer ratings, pricing patterns, and geographic trends can help businesses make informed decisions.

This project aims to:

- Analyze restaurant ratings distribution
- Identify pricing trends across locations
- Explore the relationship between cost and ratings
- Detect patterns in customer preferences
- Generate business insights using visualizations

---

## 📊 Dataset Information

The dataset contains restaurant-level information including:

- Restaurant Name
- Location
- Cuisine Type
- Cost for Two
- Online Order Availability
- Table Booking Availability
- Ratings
- Votes

The data was cleaned and processed before analysis.

---

## 🔎 Exploratory Data Analysis (EDA)

The following analysis was performed:

- Data cleaning & preprocessing
- Handling missing values
- Rating distribution analysis
- Cost distribution analysis
- Location-based restaurant trends
- Correlation analysis
- Visualization of key insights
